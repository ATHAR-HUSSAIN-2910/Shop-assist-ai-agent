# Return Policy

## Return Window

Customers can request a return within **30 days of delivery**.

Requests made after 30 days from the delivery date are not eligible
for return.

## Return Conditions

To be eligible for a return, the product must be:

- Unused and in its original condition
- Returned with all original packaging
- Returned with all accessories, manuals, and free gifts included
- Accompanied by proof of purchase (order ID is sufficient)

## Non-Returnable Items

The following items are **not eligible** for return:

- Personal care and hygiene products (e.g., cosmetics, skincare)
- Innerwear and swimwear
- Perishable goods
- Digital products and gift cards
- Items marked "Final Sale" or "Non-Returnable" on the product page

## How to Initiate a Return

1. Go to the customer's order page.
2. Select the item to return.
3. Choose a reason for return.
4. Schedule a pickup or drop-off, depending on the location.
5. Print or save the return label provided.

## Return Pickup

Return pickups are usually scheduled within **2–3 business days**
of the request. Pickup availability depends on the customer's
location.

## After the Return

Once the returned product is received, it goes through inspection.
The inspection usually takes **2–3 business days**.

If the return is approved, the refund process begins automatically.
If the return is rejected, the product is sent back to the customer
along with the reason for rejection.

## Exchanges

Exchanges are not currently supported. Customers who want a different
product should return the original item for a refund and place a
new order.
